University Agent

University Agent は、運営者本人が自分の大学の授業資料を整理するために作った個人用のツールです。一般向けのサービスとして提供していません。

運営者本人の Google ドライブに、本人がアップロードした授業の録音・資料と、その文字起こしを保存します。Google ドライブへのアクセス権限は drive.file（このアプリが作成したファイルだけ）に限っています。

  • プライバシーポリシー
  • 利用規約

University Agent is a personal tool that its operator uses to organize their own university course materials. It is not offered as a service to the public. It stores files the operator uploads, and their transcripts, in the operator's own Google Drive, using only the drive.file scope (files created by this app).
